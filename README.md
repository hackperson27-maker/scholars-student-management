# Student Management System

A beginner-friendly web project for managing student details, attendance and marks.

## Features
- Add student details
- View student records
- Search students
- Delete students
- Saves data in the browser using localStorage
- Responsive design for laptop and mobile

## Technologies
- HTML
- CSS
- JavaScript

## How to run
Open `index.html` in a web browser.
